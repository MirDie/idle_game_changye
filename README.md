# Fantasy Idle Grid Expedition

一个面向手机竖屏的 **6×6 自动探索 + 挂机刷宝 RPG**。

当前项目目标不是“小型原型”，而是做成一个完整的长期挂机 RPG：保留职业、战斗、怪物生态、Boss、装备、词缀、传奇构筑、自动养成、商店、存档、离线、成就、天气和最终通关等完整系统，只把连续开放世界替换为 6×6 自动格子探索。

## 核心变化

```text
连续开放地图 / A* / LOS / 自由坐标移动
                 ↓
            6×6 Tile Floor
                 ↓
       自动探索 / 迷雾 / BFS 回溯
                 ↓
怪物 / 稀有 / 精英 / 门卫 / Boss / 宝箱 / 资源 / 事件
                 ↓
              下一层
```

## 当前已接入的内容规模

- 8 个区域，每区 10 层主推进结构。
- 5 个职业：战士、盗贼、法师、牧师、游侠。
- 每职业 6 个 Talent 槽位，并具备自动 Talent 分配。
- 48 个普通怪条目。
- 16 个稀有怪条目。
- 24 个精英条目。
- 32 个楼层 / 巡游 Boss 条目。
- 8 个区域 Boss。
- 5 个装备槽。
- 每槽 8 个基础底材，共 40 个。
- 5 档装备稀有度。
- 24 条普通词缀。
- 16 条传奇构筑效果定义。
- 12 项首批成就。
- 5 种天气定义。

## 当前玩法

- 每层固定 `6×6 = 36` 个格子，迷雾逐步揭开。
- 自动从相邻格探索，必要时 BFS 回到最近未探索边界。
- 自动探索支持 `均衡 / 猎杀 Boss / 寻宝` 三种策略。
- 格子可出现普通怪、稀有怪、精英、Boss 门卫、巡游 Boss、世界 Boss、楼层 Boss、区域 Boss、宝箱、资源、陷阱、伏击、巢穴、营地、行商、神龛、治疗点和出口。
- 每层至少有一个核心 Boss；第 3/6/9 层提高巡游 Boss 密度；第 10 层为区域 Boss。
- Boss 门卫未击败前，核心 Boss 结界不会解除。
- 世界 Boss 不会替代楼层 Boss，也不会错误解锁出口。
- 战斗支持普通攻击、职业技能、Boss 三阶段强化、暴击、闪避、职业被动和三种战斗策略。
- 自动战斗、升级、金币、Boss 精华、装备掉落、自动换装构成持续挂机循环。
- 装备实际使用 40 底材、5 稀有度、24 词缀与传奇效果数据。
- 已加入重铸石 / Boss 精华重铸入口。
- 已加入营地商店、行商格和区域材料。
- 已加入主档 + 备份档、15 秒自动保存、关键事件即时保存。
- 已加入最长 8 小时离线收益。
- 已加入成就状态与成就 UI。
- 已加入最终区域完成后的通关摘要和无尽轮回入口。
