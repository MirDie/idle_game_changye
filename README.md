# Fantasy Idle Grid Expedition

一个面向手机竖屏的 **6×6 自动探索 + 挂机刷宝 RPG**。

## 当前玩法

- 每层固定 `6×6 = 36` 个格子，迷雾逐步揭开。
- 角色自动从相邻格开始探索，不需要开放世界坐标、碰撞或 A* 导航。
- 格子包含普通怪、稀有怪、精英、巡游 Boss、楼层 Boss、区域 Boss、世界 Boss、宝箱、资源、陷阱、伏击、巢穴、营地、行商、神龛、治疗点与出口。
- 每层至少 1 个楼层 Boss；第 3/6/9 层固定增加巡游 Boss；第 10 层为区域 Boss。
- 出口可以提前发现，但击败必要 Boss 前保持封印。
- 自动战斗、升级、金币、Boss 精华、装备掉落、稀有度、词缀、传奇效果和自动换装形成完整循环。
- 8 个区域、5 个职业、Talent、商店、重铸、成就、离线收益、存档、最终通关与无尽推进均纳入完整游戏结构。
- 自动探索支持 `均衡 / 猎杀 Boss / 寻宝` 等策略。
- 支持 `1× / 2× / 4×` 探索速度、暂停以及重置当前层。

## 运行

无需构建工具，直接打开：

```text
index.html
```

也可以使用任意静态服务器。

## 核心循环

```text
6×6 自动探索
→ 遭遇普通 / 稀有 / 精英 / Boss
→ 自动战斗
→ 装备与材料掉落
→ 自动换装 / Build / Talent / 重铸
→ 解锁出口
→ 下一层
→ 区域 Boss
→ 新区域
→ 最终通关 / 无尽推进
```

## 项目定位

本仓库作为独立项目维护。地图探索层采用 6×6 自动格子系统，其他系统围绕完整挂机刷宝 RPG 持续扩展。

完整功能范围与验收项见 `FEATURE_PARITY.md`。
