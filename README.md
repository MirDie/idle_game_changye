# Fantasy Idle Grid Expedition

一个面向手机竖屏的 **6×6 自动探索 + 挂机刷宝 RPG** 原型。

## 当前玩法

- 每层固定 `6×6 = 36` 个格子，迷雾逐步揭开。
- 角色自动从相邻格开始探索，不需要开放世界坐标、碰撞或 A* 导航。
- 格子包含普通怪、精英、巡游 Boss、楼层 Boss、宝箱、神龛、治疗点与出口。
- 每层至少 1 个楼层 Boss；第 3/6/9 层固定生成 2 个巡游 Boss；其他层也有概率生成巡游 Boss。
- 第 10 层楼层 Boss 升级为区域 Boss，击败后进入下一个区域。
- 出口可以提前发现，但击败楼层/区域 Boss 前保持封印。
- 自动战斗、升级、金币、Boss 精华、装备掉落、稀有度和自动换装已经形成完整循环。
- Boss 来源拥有更高稀有装备权重；区域 Boss 会额外掉落多件装备。
- 自动探索支持三种策略：`均衡 / 猎杀 Boss / 寻宝`。
- 支持 `1× / 2× / 4×` 探索速度、暂停以及重置当前层。

## 运行

无需构建工具，直接打开：

```text
index.html
```

也可以使用任意静态服务器。

## 设计目的

这一版专门验证：

```text
自动探索格子
→ 遇怪自动战斗
→ 多级 Boss
→ 掉装备
→ 自动比较换装
→ 找到并解锁出口
→ 下一层
```

重点是保留“角色真的在地图里冒险”的观看感，同时删除连续开放地图、导航网格、碰撞、LOS 和复杂寻路带来的工程负担。

## 来源说明

玩法方向参考了公开项目 `RusianHu/fantasy-idle-rpg` 的挂机 RPG / 探索 / 刷宝思路，但本仓库这一版为独立重写原型，没有复制其源码或美术资源。
